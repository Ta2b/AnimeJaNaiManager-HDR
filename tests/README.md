# Focused checks

Run the smallest relevant project with the paired player source through `PlatformSource` and `ReferenceExporterSource` when working in isolated checkouts. These are local fixtures, not GPU capability claims.

- `ModularStages`: four fixed categories, supported choices, imported/disabled stages and historical sizing.
- `NavigationUi`: profile identity, navigation, preservation and layout.
- `PreparationUi`: owned worker lifecycle and second-job cancellation.
- `ChainCleanup`, `ConversionRetirement`: historical profiles/global conversion migration.
- `InterpolationPersistence`, `ProfileRoundTrip`: profile persistence and unknown data.
- `TrueHdrSdkStore`, `TrueHdrOptionalSdkUi`: optional TrueHDR archive installation.

The former FRUC installer/protection and obsolete editor campaigns were removed in the Manager redesign. Their source and historical results remain in Git history; retirement/import preservation is covered by `ModularStages`. A prior successful campaign is not an instruction to replay every check.
